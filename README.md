# Snap Afghanistan Desktop

سامانه نصبی و آفلاین مدیریت اعضا و مراکز اسنپ افغانستان برای Windows 10/11.

## امکانات نسخه ۱.۰

- ورود امن مدیر با رمز هش‌شده
- ثبت، ویرایش، بایگانی و حذف اعضا
- کد خودکار عضویت و پیوست تذکره بیرون از دیتابیس
- مدیریت سکتورها، مراکز، قرارداد و تخفیف
- اشتراک ماهانه، سررسید، وضعیت، پرداخت و شماره رسید
- گزارش اعضا، مراکز، سکتورها، بدهکاران و درآمد
- خروجی PDF فارسی با لوگو و CSV
- یادداشت‌های دفتر، بکاپ، بازیابی و سطل زباله
- تقویم هجری شمسی و میلادی
- SQLite محلی با صفحه‌بندی و Virtualization برای بیش از ۲۰٬۰۰۰ عضو

## نصب

کاربر نهایی فقط فایل `SnapAfghanistan-Setup-1.0.0.exe` را از بخش Releases دانلود و اجرا می‌کند. برنامه در مرورگر باز نمی‌شود و نیازی به Python، SDK یا اجرای فایل‌های Build ندارد.

اطلاعات اجرایی در این مسیر مستقل از فایل‌های برنامه ذخیره می‌شود:

`%LOCALAPPDATA%\SnapAfghanistan\Data`

حذف یا آپدیت برنامه، این پوشه را پاک نمی‌کند.

## ساخت خودکار

GitHub Actions برنامه را روی Windows می‌سازد، آزمایش PDF و دیتابیس را اجرا می‌کند و سپس Setup.exe را با Inno Setup تولید می‌کند.
